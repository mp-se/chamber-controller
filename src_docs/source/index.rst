Chamber Controller Documentation
################################

Welcome to the documentation for **Chamber Controller**, a temperature
controller for fermentation chambers and fridges. It uses the BrewPi PID
controller library to manage heating, cooling, and an optional fan from chamber
and beer temperature sensors. A web interface provides setup, status, and
integrations.

.. tip::

   New to the controller? Start with :doc:`installation`, then use
   :doc:`configuration` to select sensors, configure outputs, and set a target.
