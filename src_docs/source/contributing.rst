.. _contributing:

Contributing
############

Issues, fixes, and feature discussions are welcome through the
`Chamber Controller GitHub repository <https://github.com/mp-se/chamber-controller>`_.
Include the firmware version, board, relevant configuration, and a short
serial log excerpt when reporting a problem. Remove Wi-Fi passwords, tokens,
and other credentials before sharing logs or configuration files.

For changes to control behavior, describe the sensor setup and the conditions
used to evaluate the change. Test controller changes with the simulator where
possible and with representative sensor data before using them on powered
heating or refrigeration equipment. See :doc:`compiling` for local build and
mock UI instructions.
